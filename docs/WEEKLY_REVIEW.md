# WEEKLY_REVIEW

## 目的

週1回、利用実態と摩擦を振り返り、次リリース（`v0.1.x`）に入れる改善を絞るためのテンプレートです。

## 使い方

1. `docs/OPS_LOG.md` から今週分を抽出
2. 摩擦トップ3を決める
3. 採用する改善を最大3件に絞る
4. 見送る改善は理由を残す
5. 次リリース予定を更新する

## テンプレート（コピペ用）

```markdown
# Weekly Review (YYYY-MM-DD)

## 今週の利用状況
- 触った回数の傾向:
- 補足:

1.
2.
3.

## 採用する改善（最大3）
1. （Issue #）
2. （Issue #）
3. （Issue #）

## 見送る改善
- 内容:
  - 理由: 過剰 / コスト / スコープ外

## 次リリース予定（v0.1.x）
- 対象バージョン:
- 予定内容:
```
