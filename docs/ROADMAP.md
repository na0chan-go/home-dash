# ROADMAP

## 目的

HomeDash は家庭ホワイトボード（連絡共有 / 買い物メモ / ゴミ確認）を、
家庭内で迷わず使える形で継続運用することを目的にします。

## v0.1.x（運用安定化）

2週間運用で見えた摩擦を小さくし、毎日使っても困らない状態を優先します。

- タブレット操作時の視認性や誤操作防止の微調整
- オフライン・スリープ復帰時の安定性改善
- ドキュメントと運用手順の不足を補強

## v0.2.x（MVP1の検討）

MVP0の利用定着を前提に、必要性が明確なものだけを控えめに検討します。

- 例: 天気情報を右上に小さく表示するなど、主機能を邪魔しない追加
- 既存の「連絡/買い物/ゴミ」が埋もれない構成を維持

## スコープ外（原則やらない）

- 在庫管理のような入力負荷が高い機能
- 家庭運用に対して保守コストが大きい機能
- MVP0の主目的から離れる情報集約

判断に迷う提案は、Issueで「目的」と「MVP0逸脱チェック」を先に確認してから進めます。
