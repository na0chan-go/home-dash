# OPS_LOG

## 目的

- 毎日1分で「困ったこと」を記録する
- 週1回、記録をまとめてIssue化する
- 感覚ではなく、実運用の摩擦をもとに改善優先度を決める

## 使い方（毎日）

1. その日使っていて気になった点を1つだけでも記録する
2. 詳しく書けない日は「影響」と「困ったこと」だけでも残す
3. 週末に `docs/TRIAGE.md` の手順でIssue化する

## 記録テンプレ（コピペ用）

```markdown
### YYYY-MM-DD
- 触った回数: （例: 5回）
- 困ったこと:
  - （1〜3行で記載）
- 影響: 大 / 中 / 小
- その場しのぎ: （あれば）
- メモ: （任意）
```

## 記録例

```markdown
### 2026-03-04
- 触った回数: 6回
- 困ったこと:
  - 買い物の削除ボタンを押したつもりで完了を押してしまうことがあった。
- 影響: 中
- その場しのぎ: 完了を戻して再操作した。
- メモ: ボタン間隔か色分けを見直す余地あり。
```
